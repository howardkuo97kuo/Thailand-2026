# 清邁行程網站：做法回顧（10/12 – 10/23）

## 結論
這套做法值得重複使用：單一 repo、無建置步驟、Firebase 即時共編、Claude 透過 GitHub Actions 讀寫資料。但目前「清邁」寫死在程式、設定與 workflow 裡，直接複製會把清邁的日期、地點、金鑰路徑一起帶走。要做台灣站，先把專屬內容抽成設定，再用同一份指引（見 `docs/trip-site-template.md`）開新 repo。

## 架構一覽
| 層 | 現況 | 評價 |
|---|---|---|
| 前端 | 單一 `index.html`（約 2,450 行、212 KB），含樣式、版面、邏輯與 `PLAN`／`LODGING`／`BOOKINGS`／`FLIGHTS` 等資料 | 部署最簡單，但資料和程式混在一起，是複製成本最高的地方 |
| 地點庫 | `places.json`（分類、地區、地點、營業時段、座標、Place ID、愛心預設） | 設計好，欄位通用，可直接沿用格式 |
| 即時資料 | Firebase Realtime DB，網頁直接用 REST 讀寫，規則在 Firebase 主控台 | 共編順暢；但規則不在 repo，換站要重做 |
| 離線 | `sw.js` 快取頁面、資料、圖磚；旅途中很有用 | 沿用，只要記得改快取版本號 |
| 問 AI | Cloudflare Worker 呼叫 Gemini 免費層，限定只答清邁 | 限制語句與來源網址要換；額度與限流有已知缺口 |
| 排程工具 | `inbox_agent.py`、`feedback_agent.py` 處理推薦與意見 | 工具通用，但路徑與名稱帶 `cnx` |
| Claude 讀寫 | `read-firebase.yml`、`write-plan.yml` 透過 GitHub Actions，寫入前備份、比對 `ts`、讀回確認 | 這是最大的成果，可整套搬 |

## 做得好（建議保留）
- **無建置、推送即上線**：改完推 `main` 約 1 分鐘生效，適合旅途中應急。
- **Claude 直接寫行程**：備份、衝突檢查、讀回確認三道保護，10/17 驗證後一個晚餐更新約 1 分鐘。
- **決策用點選卡片**：符合 Howard 的偏好，旅途中用手機最快。
- **網站維護集中一個討論串**：避免多串同時改同一個檔。
- **行程自帶檢查**：營業時間警告 `hoursWarn`、交通時間 `travelWarn`、睡眠 `sleepWarn` 已經在 CLAUDE.md 記載，檢查報告的 B、D 建議實際上已做。
- **預訂即鎖定**：已訂項目不能被移動或刪除，避免誤改。
- **CLAUDE.md 記下踩過的坑**：例如刪程式前要 grep 所有識別字（`ago()` 事件）。

## 可以更好
| 問題 | 影響 | 下次怎麼做 |
|---|---|---|
| 清邁專屬值寫死：日期 regex（write-plan 只允許 `2026-10-15` 到 `10-20`）、Firebase 專案網址、`Asia/Bangkok`、Worker 名稱 `cnx-chat`、`cnxPlan` 等 localStorage 鍵、tab 名稱（按摩、課程體驗） | 複製後要逐處手改，漏一處就壞 | 抽到單一 `config` 區塊（或 `config.json`），workflow 從那裡讀 |
| 資料與程式混在 `index.html` | 改一天行程要動 200 KB 的檔案，容易出錯，也難複製 | 預設行程、住宿、訂位、航班移到 `trip.json`；`index.html` 只放邏輯 |
| 早期雲端連不到 Firebase | 一度只能做「建議調整」等人按套用，每次約 10 分鐘 | 新站第一天就建好讀寫 workflow 與密鑰，不要事後補 |
| 同一天被不同需求反覆改 | 每次都要測試加部署 | 同一天的改動先合併成一次寫入 |
| 事實沒重讀就回答 | 曾說火鍋三人都愛心，其實 Charlie 沒有 | 回報誰愛心之前先重新讀取最新資料 |
| 規則不在 repo | Firebase 規則只在主控台，換站容易漏設 | 把規則 JSON 放進 repo 存檔（不含密鑰），文件標明「需手動貼上」 |
| 問 AI 限流不可靠 | 偽造來源可耗盡每日額度 | 需要時改用 Cloudflare KV 或 rate-limit binding；範本標明這是已知取捨 |
| 提醒靠人工 | Makkha、回程航班號碼等待辦項目會被漏掉 | 「待訂」清單由資料自動產生（現有 `needsBooking`），並在 CLAUDE.md 維護開放項目 |
| 密鑰與金鑰位置分散 | `GMAPS_KEY` 在 html、Firebase 密鑰在 Secrets、Gemini 金鑰在 Cloudflare | 範本列出每把金鑰的位置、限制條件與換法 |
